# Warp integration

Explore **virtual arrays** and **GPU counts that control captured work**. The Dynamic count guide and count examples follow [Warp PR1](https://github.com/ooctipus/warp/pull/1); virtual-array syntax remains a separate proposal. These fork APIs are not yet in Warp main.

For the current Newton, MJWarp and IsaacLab implementation, see [Integration, from reset to physics](../integration.md).
