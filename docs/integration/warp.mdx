# Warp integration

This proposal focuses on two capabilities: **virtual arrays** and **GPU counts that control captured work**. The examples compare fixed-size execution, Warp main with GPU Components, and proposed Warp support. APIs implemented in our fork are distinguished from proposed additions to Warp main.

For the current Newton, MJWarp and IsaacLab implementation, see [Integration, from reset to physics](../integration.md).
